## Embed a public GA4 dashboard with Looker Studio (no API keys)

You already ship **gtag** and collect page views in **Google Analytics 4**. Opening the Analytics UI every time you want a glance at traffic is slow, and not every organizer should get Admin access.

This guide shows a **public, unlisted** page on your static site (for example `/stats`) that **embeds a Looker Studio report**. Viewers do not sign in. You do **not** put API keys or service accounts in the repo. You set the report up **once** by hand; the page only loads an iframe.

This follows [Set up Google Analytics 4 on a static site (gtag, CSP, and Amplify)](https://dev.to/jajera/set-up-google-analytics-4-on-a-static-site-gtag-csp-and-amplify-60c). You need a working Measurement ID (`G-...`) first.

```text
  Browser  -->  your static host (/stats)
                    |
                    +--> iframe  -->  Looker Studio (public link)
                                          |
                                          +--> reads GA4 property
```

---

### 1. Overview

- Own GA4 **and** the Looker Studio report under an **org** Google account (not a personal Gmail).
- Create a simple Looker Studio report connected to your GA4 property.
- Share the report as **Anyone with the link can view**.
- Copy the **embed** URL (`lookerstudio.google.com/embed/reporting/...`).
- Add an unlisted `/stats` page that iframes that URL (config in JSON or env).
- Skip nav/footer links; use `noindex` so search is less likely to list it.
- Treat the URL as **obscurity**, not a secret—anyone who learns it can see the numbers.

---

### 2. Prerequisites

- A GA4 **web** stream already sending hits (see the gtag article above).
- Access to create reports in [Looker Studio](https://lookerstudio.google.com/).
- A **shared org** Google account that should **own** the report long-term.
- A static site you can deploy (Astro, plain HTML, Amplify, S3, and so on).
- Agreement that traffic numbers on that URL are **OK to be public**.

---

### 3. Why not the Analytics Data API?

| Approach | Secrets in repo? | Tied to a person? | Effort |
| --- | --- | --- | --- |
| Looker Studio public embed | No | Only if a personal account owns the report | Low |
| GA Data API + Lambda + service account | Yes (secret store) | No, if org-owned | High |
| Give everyone GA Admin | No | Access sprawl | Bad fit |

Use the API path only if you need custom charts or private auth on your own domain. For “open `/stats` and see charts,” the embed is enough.

---

### 4. Use an org Google account

1. Sign in to Google as the **committee / org** account (for example a shared inbox the group controls).
2. Confirm that account can open your GA4 property (**Admin → Property access management**).
3. Create the Looker Studio report while signed in as that account.

If a volunteer’s personal Gmail owns the report, the embed can break when they leave. Transfer ownership to the org account if you already built it personally.

---

### 5. Create the Looker Studio report

1. Open [Looker Studio](https://lookerstudio.google.com/) → **Create** → **Report**.
2. **Add data** → **Google Analytics** → pick the GA4 property for your site.
3. Authorize if prompted (org account must have at least Viewer on the property).
4. Add a few charts you care about, for example:
   - Users / sessions over the last 28 days
   - Top pages by views
   - Traffic by country or device
5. Name the report clearly (for example `awsug.nz traffic`).
6. **File → Share** (or the Share button):
   - **Anyone with the link** → **Viewer**
   - Do **not** require sign-in for viewers

You are not granting GA Admin. Looker Studio only **reads** the property for people who open the shared report or embed.

---

### 6. Copy the embed URL

1. In Looker Studio: **File → Embed report** (wording may be **Embed** under Share).
2. Enable embedding if asked.
3. Copy the iframe `src` only. It looks like:

```text
https://lookerstudio.google.com/embed/reporting/REPORT_ID/page/PAGE_ID
```

Store that string in site config (example JSON field):

```json
{
  "googleAnalyticsId": "G-XXXXXXXX",
  "lookerStudioEmbedUrl": "https://lookerstudio.google.com/embed/reporting/…/page/…"
}
```

No API key. The URL is the whole integration.

---

### 7. Add an unlisted `/stats` page

Keep the page out of the main nav and footer. Mark it `noindex` (and omit from search indexes if you use Pagefind or similar).

Minimal HTML shape:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <meta name="robots" content="noindex, nofollow" />
    <title>Site traffic</title>
  </head>
  <body>
    <h1>Site traffic</h1>
    <iframe
      src="https://lookerstudio.google.com/embed/reporting/REPORT_ID/page/PAGE_ID"
      title="Site traffic dashboard"
      style="width:100%;height:80vh;border:0"
      allowfullscreen
      loading="lazy"
    ></iframe>
  </body>
</html>
```

In a layout framework, read `lookerStudioEmbedUrl` from config and only render the iframe when it is set. Setup instructions belong in a README or this article—not on the public page.

**CSP:** if you use a strict Content-Security-Policy, allow the embed host under `frame-src` (and related directives as needed), for example:

```text
frame-src https://lookerstudio.google.com;
```

Redeploy after changing CSP.

---

### 8. Obscurity vs secret

- **Not linked** from the homepage ≠ private.
- Anyone who has the URL (or a crawler that finds it) can view the same charts.
- `noindex` reduces search listing; it does not authenticate users.
- Fine for open community traffic stats. Wrong for confidential product metrics.

Share the URL with organizers in chat when needed. You do not need to publish it on the site.

### 10. Troubleshooting

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| Blank iframe / sign-in wall | Report not shared as “anyone with the link” | Share → Anyone with the link → Viewer; re-copy embed URL |
| “Can’t access” in embed | Wrong account owns GA or report | Grant org account GA Viewer; recreate or transfer report |
| Iframe blocked by browser | CSP `frame-src` / `frame-ancestors` | Allow `https://lookerstudio.google.com`; redeploy |
| Charts empty | No GA4 hits yet, or wrong property | Confirm Realtime in Analytics; check data source in Looker Studio |
| Embed worked, then died | Personal owner left / account closed | Transfer report + data source to org Google account |
| Page shows up in Google Search | Missing noindex / linked from elsewhere | Add robots noindex; remove accidental nav links; request removal if needed |
